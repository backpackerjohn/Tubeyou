# Phase 3 Finalist Validation — Proof-Channel Trajectories (YouTube Data API, 2026-07-19)

Method: for each finalist's candidate proof channels, pulled the uploads playlist (25 most recent,
`playlistItems?part=contentDetails`) and stats+durations for the 15 newest
(`videos?part=statistics,contentDetails`). All numbers exact API returns, fetched 2026-07-19.
Durations matter: **Shorts views must not be scored as long-form ad inventory** (Shorts RPM is a
different, far lower product). This check reclassified several channels the audit had credited.

evidence; no further API spend justified. **Eliminated** (revisitable if real RPM data surfaces).
